# Reef Dream v0.8 Animated (Android TV 9)
A realistic photo reef background with independently animated fish image layers, bubbles, and TV DreamService.
This is photo-based 2.5D animation, NOT true textured 3D models. Fish sprites are soft-masked crops from the reef image; the background still contains static fish.
Build: Gradle 8.7, JDK 17, Android SDK 35. Run `gradle :app:assembleDebug` from the project root.
APK: app/build/outputs/apk/debug/app-debug.apk
Different debug signing keys may require uninstalling previous version (backup first).
